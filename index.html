📊 System Architecture & NLP Pipeline (Project Viva Overview)

1. Serverless Proxy (/api/news)

Abstracts API credentials on Vercel Edge Functions, normalizes multi-source JSON feeds, and prevents CORS & client key exposure.

2. Regex Text Sanitization

Strips raw HTML tags, publisher suffixes, URLs, and character-count artifacts ([+chars]) for clean speech synthesis.

3. Lexicon NLP Sentiment

Tokenizes headlines & abstracts, filters English stop-words, computes polarity scores (Positive/Neutral/Critical), and extracts TF topic tags.

4. Dual-Anchor Audio Queue

Solves Chrome's 15-second Web Speech API timeout by chunking articles into sequential utterances with alternating Lead & Co-Anchor voices.

5. Boundary-Sync Teleprompter

Listens to SpeechSynthesisUtterance.onboundary word-offset events to render real-time karaoke highlighting and card auto-scroll.

6. High-Availability Fallback

Includes automatic offline/rate-limit resilience so the application remains 100% functional even during API outages.
